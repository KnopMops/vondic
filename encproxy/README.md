# EncProxy — Zero-Trust Traffic & Cryptography Engine

Автономный локальный прокси-сервер и центр управления криптографией для платформы **Vondic**.

---

## 🎯 Назначение

EncProxy разработан для пользователей с **моделью нулевого доверия (Zero-Trust)**:
1. **Полная изоляция от сервера**: Сервер Vondic никогда не видит открытый текст сообщений и не владеет приватными ключами.
2. **Слепая аутентификация (Blind Auth)**: Сервер проверяет криптографическую подпись Ed25519 над метаданными (отправитель, получатель, хеш шифротекста, метка времени). Это гарантирует серверу, что запрос отправлен легитимным пользователем, но не раскрывает содержимое.
3. **EncProxy to Unwrapped**: Автоматическая сквозная расшифровка сообщений от авторизованных собеседников. Пользователь указывает, с какими контактами общаться через EncProxy.
4. **Инспектор трафика и модификатор заголовков**: Перехват, глубокий анализ пакетов, маскировка отпечатков браузера (`User-Agent`, `Sec-Ch-Ua`, `Client-Hints`) и внедрение пользовательских заголовков на лету.

---

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r encproxy/requirements.txt
```

### 2. Запуск приложения с графическим интерфейсом (PyQt6)
```bash
python -m encproxy.main
```

### 3. Запуск в фоновом (headless / консольном) режиме
```bash
python -m encproxy.main --headless --port 8888 --target https://vondic.ru
```

## 🔑 Архитектура шифрования

| Компонент | Алгоритм | Назначение |
|---|---|---|
| **Подпись метаданных** | `Ed25519` | Слепая верификация запросов на сервере |
| **Обмен ключами** | `X25519 (ECDH)` | Установление сессионных ключей с пирами |
| **Симметричный шифр** | `ChaCha20-Poly1305` / `AES-256-GCM` | Шифрование полезной нагрузки сообщений |
| **Деривация ключей** | `HKDF-SHA256` | Генерация общего сессионного ключа |

## 📋 Вкладки интерфейса

1. **Панель управления (Dashboard)**:
   - Включение и отключение перехвата трафика одной кнопкой.
   - Настройка слушающего адреса (`127.0.0.1`), порта (`8888`) и апстрима.
   - Счётчики перехваченных, модифицированных и зашифрованных пакетов.
2. **Инспектор трафика (Traffic Inspector)**:
   - Живой журнал всех HTTP-запросов и ответов.
   - Инспекция заголовков и форматированный просмотр JSON/Raw тел запросов.
   - Фильтрация по эндпоинтам и методам.
3. **Правила подмены заголовков (Header Rules)**:
   - Подмена User-Agent.
   - Удаление телеметрии и фингерпринтов.
   - Добавление кастомных заголовков.
4. **Криптография и ключи**:
   - Выбор симметричного шифра (`ChaCha20` или `AES-GCM`).
   - Экспорт открытых ключей и отпечатка (Fingerprint).
   - Безопасная перегенерация ключей.
5. **Защищенные собеседники (EncProxy to Unwrapped)**:
   - Список собеседников, переписка с которыми принудительно шифруется.
   - Одобрение входящих запросов на установление зашифрованного канала.
